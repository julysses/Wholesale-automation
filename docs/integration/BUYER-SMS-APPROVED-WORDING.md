## Actual flow

An administrator creates a one-time private link after a buyer requests enrollment.
The app does not send the invitation. The buyer enters the number already bound to
the invitation and saves an optional choice. Links expire after seven days; only
the token hash is stored, and the token travels in the URL fragment rather than
server paths or query strings. Saved choices have immutable receipts.

A positive choice is retained for administrator review and does not enable SMS.
A refusal keeps buyer SMS off immediately. Later refusals prevent older positive
requests from reactivating the buyer. The form does not prove phone ownership,
clear DNC, grant AI-call consent or send a confirmation text. Sender/campaign
approval, controlled handset tests and release review remain separate requirements.
